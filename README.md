# NV Atlas: Nominalization in English-Chinese Subtitles

An interactive corpus explorer built for the 2026R1 Translation Technology in the Age of AI final project.

## What is included

- 500 English-Simplified Chinese sentence pairs from OPUS OpenSubtitles 2024 (`en-zh_CN`)
- Search across English, Chinese, and key terms
- Filters for translation strategy and human-checked status
- Linked network graph, treemap, heatmap, KWIC view, and sortable data table
- Shareable URL state and filtered CSV export
- English and Traditional Chinese interface
- Learning report, codebook, and AI use declaration

## Run locally

The site is static, but it loads `data/corpus.json` with `fetch`, so use a local web server rather than opening `index.html` directly.

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Data

The source CSV is `NVAtlas-AI-Agent.csv`. The public data file is generated by:

```bash
python3 scripts/build_data.py
```

The build script adds the required `source`, `category`, `human_checked`, `unit`, `key_term`, and `rationale` fields. It uses a fixed random seed (`2026`) to mark 50 entries as human checked.

Source: [OPUS OpenSubtitles 2024](https://opus.nlpl.eu/legacy/OpenSubtitles-v2024.php). Please also see [OpenSubtitles](https://www.opensubtitles.org/). The corpus contains short subtitle excerpts for coursework and public display; source attribution is retained in every entry.
